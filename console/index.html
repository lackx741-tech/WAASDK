One-Command Deploy

        

          
SSH into your VPS and run:

          
git clone https://github.com/lackx741-tech/WAASDK.git
cd WAASDK/backend
cp .env.example .env
# Edit .env with your real values
nano .env
# Start everything
docker compose -f docker-compose.prod.yml up -d
